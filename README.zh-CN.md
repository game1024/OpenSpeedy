# 🚀 特性
- 快捷变速
- 现代化UI
- 同时可以支持x86和x64平台进程
- 无内核侵入性，Ring3层Hook，不破坏系统内核
- 开机静默自启动（无主界面、弹窗与提示，仅驻留托盘）
- 指定游戏自动加速（持久化进程名与倍率/档位，检测到进程启动即自动应用）


# 💾 安装
📦 **方式1: Winget**

``` powershell
# 安装命令如下
# 指定准确的软件包 ID 和来源，避免与 Microsoft Store 中的同名软件冲突
winget install --id Game1024.OpenSpeedy --exact --source winget

# 打开一个新的终端，运行openspeedy
openspeedy
```

📥 **方式2: 手动下载**

访问 [安装页面](https://github.com/game1024/OpenSpeedy/releases) 下载最新版本


🎮 **方式3: Steam（可选）**

在 [Steam 商店](https://store.steampowered.com/app/5010920/OpenSpeedy) 获取，此为可选的安装方式。


# 💻 操作系统要求
- OS: Windows10 以上
- 平台：x86（32位） 和 x64 （64位）

## ⚙️ 两个独立选项

两个开关位于「设置」页，互不影响，可分别开启或关闭。

**开机静默自启动**：开启后随 Windows 启动，主窗口从创建起就保持隐藏，不显示主界面、弹窗或提示，仅在系统托盘保留图标；点击托盘图标可随时恢复窗口，托盘菜单可退出。它与原有的「开机自启动」（启动后显示主界面）共用同一条系统启动项，因此二选一：开启其中一个会自动切换另一个。启动项始终带有 `--autostart` 参数，只有系统启动的会话才会保持隐藏，手动双击打开软件仍会正常显示窗口。

**自动加速**：在「设置 → 自动加速」中绑定游戏进程名，并选择自定义倍率或 1–5 档位；也可以在进程详情中点击「以当前倍率绑定」，或直接打开进程列表「名称」视图里的开关。绑定关系（进程名、可执行路径、架构、倍率或档位）写入应用数据目录的 `auto_accel.json`，档位会跟随「变速档位」中的倍率定义。此后只要检测到对应进程启动，后台线程（每 500 ms 轮询一次）就自动注入并应用已保存的倍率，无需再次选择或确认；进程退出、规则被移除或总开关关闭时会停止加速。该后台逻辑完全运行在 Rust 侧，因此即使主窗口隐藏也不会失效。

「名称」视图的开关就是规则的快捷入口：打开即新增规则并启用总开关，关闭即移除规则，与设置页的列表始终一致。旧版 `process.json` 中记住的进程名会在首次启动时自动迁移为规则（倍率取当时的全局倍率），此后只有 `auto_accel.json` 一份数据源，界面通过后台已注入的 PID 列表同步显示状态。

> 注意：速度倍率由桥接进程全局共享，多个绑定游戏同时运行时以最后启动的游戏为准。配置保存在 `%APPDATA%/com.game1024.openspeedy/` 下的 `boot_launch.json` 与 `auto_accel.json`。

# 🔧 技术原理

编译环境要求：
- [Node.js](https://nodejs.org/) 18+
- [Rust](https://www.rust-lang.org/)
- [CMake](https://cmake.org/)
- [Visual Studio](https://visualstudio.microsoft.com/)（含 C++ 桌面开发工作负载）

编译命令：

``` powershell
npm run tauri dev
```

OpenSpeedy 通过 Hook 以下 Windows 系统时间函数来实现游戏速度调整：

|函数名	| 所属库 |	功能 |
|--------|----------|------------------|
|Sleep|user32.dll|线程休眠|
|SetTimer|user32.dll|创建基于消息的计时器|
|timeGetTime | winmm.dll	| 获取系统启动后经过的毫秒数 |
|GetTickCount | kernel32.dll	| 获取系统启动后经过的毫秒数 |
|GetTickCount64	| kernel32.dll	| 获取系统启动后经过的毫秒数(64位) |
|QueryPerformanceCounter |	kernel32.dll	| 高精度性能计数器 |
|GetSystemTimeAsFileTime |	kernel32.dll	| 获取系统时间 |
|GetSystemTimePreciseAsFileTime |	kernel32.dll	| 获取高精度系统时间 |
|SetWaitableTimer |	kernel32.dll	| 设置可等待定时器 |
|SetWaitableTimerEx |	kernel32.dll	| 设置可等待定时器(扩展) |

# ⚠️ 注意事项
- 本工具仅供学习和研究使用
- 部分在线游戏可能有反作弊系统，使用本工具可能导致账号被封禁
- 过度加速可能导致游戏物理引擎异常或崩溃
- 不建议在竞技类在线游戏中使用
- 开源产品不带数字签名，可能被杀毒软件误报
